# 道具体系与药物速查

## 道具格基本规则
- 每个角色**20格道具**，角色与其宝宝**共用**同一份道具
- 宝宝消耗道具 = 角色道具减少，必须统一计算剩余量
- **道具打光基本等于输**，资源管理是竞技馆/长局的核心胜负手
- 20格需在以下类型中分配：

| 类型 | 代表道具 | 用途 |
|------|---------|------|
| 解封 | 五龙丹 | 解禁锢等封类异常 |
| 回血+疗伤 | 金香玉、九转回魂丹 | 补血/疗伤/复活 |
| 回蓝 | 回蓝药（定神香等） | 保证HS门派技能可用 |
| 疗伤专用 | 小还丹/千年保心丹 | 伤势状态必用 |
| 补愤怒 | 酒 | 对抗笑里藏刀/保证特技资源 |

## 我方标准道具配置（每人20格）

| 道具 | 数量 | 用途 |
|------|------|------|
| 五龙丹 | 5-6个 | 解禁锢/封类异常 |
| 大金香玉 | 5个 | 大量回血 |
| 九转回魂丹 | 3-4个 | 复活+回血+疗伤 |
| 回蓝药 | 少量 | 保证HS门派技能 |
| 酒 | 少量 | 补愤怒，应对笑里藏刀 |

**合计约18-20格，几乎满载，无冗余。**

## 道具管理原则
- 五龙丹是消耗最快的——每次被禁锢就要用，对面频繁禁锢会快速榨干
- 九转不足时，倒地角色只能靠奶妈特技复活（无疗伤效果，下回合必须单奶）
- 酒/回蓝数量有限，不到必要时机不轻易消耗

## 药物效果速查

| 类型 | 药物 | 效果 | 关键点 |
|------|------|------|--------|
| **回血** | 金创药、金香玉（品质×12+150） | 补充大量气血 | 基础回血，无疗伤效果 |
| **回血+疗伤** | 小还丹、千年保心丹 | 补充大量气血+疗伤 | 伤势状态必用 |
| **复活+回血+疗伤** | 九转回魂丹、佛光舍利子 | 复活+气血+疗伤 | 比特技复活多疗伤效果 |
| **回蓝** | 风水混元丹、定神香、蛇蝎美人 | 补充大量魔法 | 保障特技/门派技能续航 |
| **解封类** | 五龙丹（品质×3+回血）| 解封类异常+气血 | 不可解大死亡禁锢/发瘟匣 |
| **解毒** | 红雪散 | 解毒+补充大量气血 | 针对剑荡宠毒 |
| **解酒** | 十香返生丸 | 解酒类异常+补充大量魔法 | 解酒类异常唯一方法 |
| **增加愤怒** | 酒（特殊道具） | 使用后增加愤怒值 | 竞技馆多备，保证特技资源充足 |

### 药品计数：追踪对面资源（2026.04 确认）

**只需追踪对面两类药品总数：**

| 药品 | 对面总数估算 | 告急线 | 指挥意义 |
|------|-----------|--------|---------|
| **五龙丹** | 25-30个（极限30个） | 用到25个基本没有五孔了 | 接近25→不用五龙解封，让封印自然消退 |
| **九转回魂丹** | 约20个 | 用到15+开始积极布局 | 九转耗尽→倒地永久无法复活→胜局锁定 |

> 每次成功点杀 = 对面消耗一颗九转；每次禁锢命中 = 对面消耗一颗五龙。累计追踪，到告急线加快点杀节奏。

**疗伤只能靠**：含疗伤的药物（小还丹/千年保心丹/九转回魂丹/佛光舍利子）或奶妈单体加血技能

### 封印机制
- **效果**：限制技能（门派技能）使用，持续**5-6回合**
- **被封期间仍可使用**：特技、法宝、普攻、防御、道具
- **不是必须立刻解**——被封5-6回合后自动解除，可用特技/法宝顶过去
- **五龙丹使用原则**：
  - HS被封但仍有特技愤怒 → **不用五龙丹**，用晶清诀/水清诀特技撑
  - 被封且特技也用不出（愤怒不足）→ 评估是否值得用五龙丹
  - 临近关键点杀回合，被封角色必须出技能 → 立即吃五龙丹
  - **常规情况下等封印自然消退，保留五龙丹应对禁锢**

**解异常对应**：
- 封类（封印）→ 五龙丹（**非必须，可等自然消退**）
- 大死亡禁锢 → 乾坤挪移特技（唯一方法）
- 发瘟匣 → 清心咒法宝
- 中毒 → 红雪散
- 酒类异常 → 十香返生丸

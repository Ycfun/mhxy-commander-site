## 站位核心原则

- **虎翼**：最强输出坐1号位（+30%），辅助/封系坐2-3号位
- **鹰啸**：封系/辅助坐2-3号位（+15%速度），输出坐4-5号位
- **龙飞**：法系输出坐3号位（+30%法伤，速度-20%对法系影响小），辅助坐1号位
- **地载**：需要耐打的角色坐1/3/4号位，输出坐2号位

## 开阵决策

```
对面虎翼 → 地载(+10%)
对面鹰啸 → 风扬/云垂(+10%) 或 雷绝(+5%)
对面地载 → 鹰啸(+10%)
对面龙飞 → 云垂(+10%) 或 鹰啸(+10%)
对面风扬 → 地载/虎翼/雷绝(+10%)
对面云垂 → 龙飞/虎翼/雷绝(+10%)
对面雷绝 → 地载/龙飞(+10%)
```

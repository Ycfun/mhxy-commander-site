# 职业知识库

## 封系职业

| 职业 | 核心特性 | 指挥定位 |
|------|---------|---------|
| **女儿** | 门派+经脉加速，速度最快（800+），无任何宠物能配速 | 一速先手，节奏锚点；被封时只能用特技/法宝 |
| **天宫** | 加血+经脉+50防+50法防，血防极高 | 耐打封系，适合长局；被封时比女儿更扛得住 |
| **方寸** | 催眠符，被催眠解除后仍跳一回合 | 短节奏打断，不适合消耗战 |
| **盘丝** | 消耗对面蓝量 | 蓝耗流，配合212消耗体系 |
| **五庄** | 可封物理/法术/特技，仅3回合且命中率低 | 不稳定，不作主力依赖 |

**主流：女儿（先手）+ 天宫（耐打）**

## 输出职业

| 职业 | 核心技能 | 指挥定位 |
|------|---------|---------|
| **大唐** | 横扫千军：单体×3连击，用后休息1回合 | 点杀专家，集火脆皮/关键目标 |
| **狮驼** | 鹰击（飞机）：打5个不同目标，叠加爪印递增伤害，用后休息1回合 | AOE清场，适合长局；竞技馆慎用 |
| **力地府** | 夜间伤害+速度大幅提升（白/夜15分钟切换） | 时间敏感型爆发，需实时感知白夜状态 |
| **魔方寸** | 法系输出，秒2，伤害高，对宝宝伤害加成极高 | 清宝宝专家 |
| **魔王** | 秒4/单烧，魔冥经脉叠加后单烧约2000-3000血（约半管） | 全能法系，版本强势 |

**大唐/狮驼使用横扫/鹰击后强制休息1回合，指挥需规划空档期保护。**
**破血狂攻：2次物理攻击，无休息，适合持续输出场景；横扫千军：3次，伤害更高但有休息。**

## 辅助职业

| 职业 | 技能 | 指挥定位 |
|------|------|---------|
| **化生** | 群体/单体回血、复活、金刚（加伤）、防御圈、速度圈 | 全能辅助，团队节奏枢纽 |
| **普陀** | 点灯（单体持续5-6回合回血+恢复伤势）、复活，无增益类技能 | 持续续航型，慢节奏首选 |

**化生每回合决策优先级：有人濒死→单体回血；全队掉血→群体回血；无威胁→提前挂增益**

**复活注意：被地府禁锢术挂上后倒地→5回合内不可复活；被大死亡禁锢倒地→10回合内不可复活**

## 防御参考基准（89级PVP）

| 角色类型 | 防御范围 | 说明 |
|---------|---------|------|
| 输出职业 | 1100-1200 | 较易被点杀 |
| 辅助/奶妈 | 1300-1400 | 耐打，点杀代价高 |

## 地府双定位

| 定位 | 核心依赖 | 适用场景 |
|------|---------|---------|
| **力地府**（输出） | 夜间爆发 | 夜间局 |
| **辅助地府** | 禁锢术（50-60%命中）+ 驱散 | 点杀配合，长局控制 |

**禁锢术点杀三步：① 地府先挂禁锢术 → ② 集火击杀 → ③ 倒地后5回合不可复活**
**必须先挂后杀，倒地后挂无效。**

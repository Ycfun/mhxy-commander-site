## 愤怒特技腰带优先级

> **70级（40怒/180防血）> 80纯愤怒腰带 >> 国标（30怒/140）**
> 国标愤怒腰带太差，不推荐。纯愤怒腰带没有防血属性，不如带属性的70级腰带。

**早打特技原则**：特技要早点打出来，早点打早点收益。没怒气就喝酒打，一个特技打出来，比无级别加的属性都多。

## 开局威胁：对面封系笑里藏刀

- **笑里藏刀效果**：特技，消耗40怒（腰带32），**降低目标愤怒值70点**
- **目标**：优先打我方HS（奶妈）或MW（魔王），开局愤怒从100直接跌到30，高消耗特技全打不出
- **解法**：喝酒补愤怒（无法用五龙丹解，不是封印类）
- **应对原则**：
  - HS被打笑里藏刀 → 立即喝酒补愤怒，乾坤挪移（108怒）优先恢复
  - MW被打笑里藏刀 → 牛劲（门派技能，耗蓝）仍可正常使用，损失相对小
  - TG速度最快(691)，圣灵之甲在对面笑里藏刀之前打出，不受影响
  - 竞技馆多备酒的原因之一就是应对笑里藏刀偷愤怒

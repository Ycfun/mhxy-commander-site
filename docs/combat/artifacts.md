# 法宝体系

## 主动法宝

| 法宝 | 效果 | 命中 | 指挥价值 |
|------|------|------|---------|
| **发瘟匣** | 3回合无技能/特技/召唤宝宝，随机平A | ~50% | 优先打奶妈/关键输出；被发瘟匣无法用五龙丹/特技解，只能清心咒 |
| **五彩娃娃** | 6回合降低承受伤害 | 必生效 | 预判点杀前挂上；与防御圈叠加极耐 |
| **清心咒** | 解除发瘟匣/摄魂 | 概率 | 发瘟匣>摄魂，优先解发瘟匣 |
| **摄魂** | 降低目标攻击/防御（地府专属）| 概率 | 挂在核心输出身上 |
| **翻天印** | 4回合内对面被动法宝无效 | 概率 | 对面挂了五彩娃娃时使用，打开点杀窗口 |
| **现形符** | 使对面变身失效 | — | ⚠️ 社区认为"脏"，一般不用 |
| **铃铛** | 概率使目标宝宝逃跑 | 概率 | 优先摇：柚子、死亡宠、隐攻 |

**所有主动法宝使用后有冷却回合，不能连续使用。**

## 被动法宝（每人最多装备3个）

| 法宝 | 效果 | 适用角色 |
|------|------|---------|
| **风袋** | +25速度/个，最多装备2个 | 所有角色 |
| **镇海珠** | 法系伤害↑ | 魔王、魔方寸 |
| **拭剑石** | 物理伤害↑ | 物理输出 |
| **七杀** | 物理伤害↑（大唐专属）| 大唐 |
| **葫芦** | 奶妈回血量↑ | 化生、普陀 |
| **金甲** | 概率-50%物理伤害 | 需要抗物理的角色 |
| **法甲** | 概率-50%法术伤害 | 需要抗法系的角色 |
| **封印强化×2** | 封印技能等级+2/个，提升命中率 | 封系（不适用地府禁锢术） |

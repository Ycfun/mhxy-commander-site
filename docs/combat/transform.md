# 变身卡

| 变身卡 | 加成 | 减少 | 适用 |
|--------|------|------|------|
| **大雾** | +20%速度 | -10%防御 | 封系极限抢速，变脆谨慎用 |
| **老鼠** | +10%速度 | 无 | 通用纯速度 |
| **如意** | +8%速度/+20灵力 | 无 | 封系/辅助均衡 |
| **红鄂** | +5%速度/+5%血量 | 无 | 辅助/奶妈均衡 |
| **血牛卡** | +10%血量 | 无 | 奶妈/天宫 |
| **炎魔神** | +20%法术伤害 | -15%血量 | 法系爆发，对面物理多时用 |
| **鸭子** | +20%法术伤害 | -10%防御 | 法系爆发，对面法系多时用 |
| **灵符卡** | +10%法术伤害 | 无 | 法系稳定无代价 |
| **小夜卡** | +5%速度/高夜战 | 无 | 物理输出（非地府，地府自带夜战） |
| **吸血鬼** | +5%物理伤害 | 无 | 力地府（已有夜战，不需小夜卡） |
| **葫芦（变身卡）** | +5%血量/降蓝耗 | 无 | 化生（解决蓝量不足）|

**夜战机制**：夜间物理伤害默认降低；有高夜战则不降低；地府门派自带，无需小夜卡。

# 基础战斗机制

## 场上单位
- **5v5**：双方各5个角色，开场各出1只宝宝 → **场上共20个单位**
- 每个角色可携带8只宝宝，同时在场只能1只
- 宝宝被击倒后可召唤下一只；8只全灭则无法再召唤
- 主动换宝宝也消耗角色本回合行动

## 每回合行动

| 单位 | 可用操作 |
|------|---------|
| **角色** | 技能、攻击、防御、法宝、特技、道具（吃药/喝酒） |
| **宝宝** | 技能、攻击、防御、道具、**保护** |

**宝宝保护机制**：
- 指定宝宝保护某个我方角色
- 该角色受到物理攻击时，宝宝分担伤害
- 与TG天神护体效果相同，但由宝宝执行
- **适用场景**：DT（4500血）被对面物理集火时，壁垒宠保护DT分担伤害；配速死亡/龟速无输出时可转做保护用途

## 行动顺序
- 按速度从高到低，角色和宝宝混排
- 速度相同时顺序不确定

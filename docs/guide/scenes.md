# PVP 场景规则

| 场景 | 回合限制 | 胜负判定 | 核心策略 |
|------|---------|---------|---------|
| 竞技馆 | 24回合 | 第24回合起每回合比倒地人数，少者胜 | 关键回合保留绝杀手段，时机控制 |
| 剑会 | 最大150回合 | 一方人物+宝宝全部倒地 | 资源管理，消耗战 |
| 皇宫 | 最大150回合 | 同剑会 | 同剑会，规则完全一致 |
| 群雄 | 56回合（1.5小时）| 同剑会 | 持续输出，团战节奏 |

**竞技馆特别注意**：24回合前双方都在积累优势，24回合起每回合结算，要在关键回合完成绝杀，不是比谁死得多而是比谁活的多。

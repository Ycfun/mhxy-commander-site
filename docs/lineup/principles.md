# 阵容选择核心原则

> 2026.04 确认

## 点杀核心组合

**大唐 + 魔王（有魔冥）** = 当前版本最合适的点杀搭配，以此为主导。

大唐是输出核心，定位是打**点杀**，不是清宝宝和打面伤。

## 双封最优解：女儿 + 方寸
- **女儿**：有一速，天宫抢不到一速
- **方寸**：失心 + 必要时催眠；FC能抢3速就尽量抢3速，比4速有用很多
- 速度优先意味着相对脆——要抢速度就接受脆，不存在又快又很硬（除非无级别装备）

## 辅助焊死：花生（化生）

## 其他职业评估

| 职业 | 适用性 |
|------|--------|
| 封天宫 | 可以打，非最优（抢不到一速） |
| 国标/力地府 | 可以玩 |
| 狮驼 | 可以玩 |
| 魔方寸 + 力五庄 | **以清宝宝为主线，非点杀打法**，不是我们的最优解 |

**我们的最优解：大唐+魔王点杀，女儿+方寸双封，花生辅助固定。**

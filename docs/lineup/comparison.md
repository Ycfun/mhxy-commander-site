# 阵容变体对比与综合评分

## 辅助地府 vs 满天地府

### 核心参数差异

| 对比项 | 辅助地府（竞技馆标准） | 满天地府（长局实验） |
|--------|-------------|------------|
| 满天花雨 | 单（DT） | 双（DF+DT） |
| 罗汉金钟 | ✅ 有（唯一真正失去的） | ❌ 无 |
| DF生存 | 5600血/1400防 | 5000血/1200防 |
| 放下屠刀 | DF携带 | MW本来就有，不受影响 |
| 攻心术/凝滞术 | DF携带 | 其他角色可分担 |
| 禁锢术 | ✅ 有（门派技能） | ✅ 有（门派技能，不受套装影响） |

**核心取舍：双满天清宝宝效率 换 罗汉金钟 + DF生存能力**

### 场景推荐

| 场景 | 推荐 | 原因 |
|------|------|------|
| 竞技馆（24回合） | **辅助地府** | 短局稳，罗汉救命，DF皮厚不拖资源 |
| 群雄（对面无强法系） | **满天地府** | 解决资源耗尽根本问题 |
| 群雄（对面双魔王/强法系） | **辅助地府** | 无罗汉扛不住法系爆发 |
| 剑会/皇宫 | **满天地府** | 长局清宝宝路线，效率碾压 |

### 满天地府特技重新分配

DF换满天套装后，原有特技需由其他角色承接：

| 原DF特技 | 承接角色 | 代价 | 说明 |
|---------|---------|------|------|
| 放下屠刀 | MW（原已有） | 无 | MW本来就有，不受影响 |
| 罗汉金钟 | **TG** | 替换妙法之护（已确定选罗汉）| TG691速先手，可在对面法系行动前打出 |
| 攻心术 | **HS** | 无（空槽） | HS有一个空余槽位，零代价承接 |
| 凝滞术 | **MW** | 无（空槽） | MW有多余槽位，零代价承接 |

**净损失：仅妙法之护（单体+10%法防，已确认弃用，换罗汉金钟）**

### 满天地府操作要点
```
前期：DF+DT普攻宝宝叠满天层数（零资源消耗）
      MW单烧宝宝（不打人物，不喂对面愤怒）
中期：满天3层后约1806伤×2，开始威胁人物
      禁锢术择机挂目标，DF+DT+MW点杀
后期：对面宝宝告急→龟速保护失效→九转快速消耗→胜
保护DF：TG天神护体 / 壁垒宠保护，防止DF被提前集火
```

### 辅助国标不适合长回合（50回合以上）的原因
- 资源消耗大，长局中容易先于对面打光资源
- 清宝宝效率低（单满天），无法快速压缩对面复活空间
- 无双封，打不了五龙丹消耗路线
- 综合来看，长局优势无法发挥，反而容易被拖垮

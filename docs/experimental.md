## 核心战术逻辑

### 满天花雨伤害积累
```
满天花雨3层 = +15%物伤
DF: 1570 × 1.15 ≈ 1806伤
DT: 1570 × 1.15 ≈ 1806伤
双满天同时到3层 → 点杀火力大幅提升
```

### MW单烧宝宝的战略价值
```
攻击宝宝 → 对面人物不受伤 → 不涨愤怒 → 对面特技资源枯竭
vs
攻击人物 → 对面人物涨愤怒 → 对面可以打特技反击
```
**结论**：MW单烧宝宝是主动压制对面愤怒资源的手段

### 宝宝配置
- MW可用3体2耐（攻宠×3 + 耐法×2）
- 其余角色配置待确认

## 分阶段打法

### 前期（满天3层之前）
```
DF + DT → 普攻宝宝，叠满天花雨层数
MW → 单烧宝宝（不打人物，不喂对面怒气）
HS → 维持状态，野兽之力给DF/DT，伯牙打对面法系
TG → 圣灵之甲开场，碎甲术降对面物防，封控对面封系
目标：DF/DT同时达到满天3层（≈1800伤），宝宝已被大量消耗
```

### 中期（满天3层后）
```
出死亡宠，开始点杀模式
DF + DT → 从清宝宝转为威胁人物
MW → 根据局势切换单烧目标（宝宝/人物）
点杀优先级：对面宝宝已稀少的角色 > 血防低的输出
```

### 后期
```
对面宝宝所剩无几 → 龟速宠失去保护作用
大死亡触发 + 禁锢 → 双保险锁定目标
点杀成功 → 无宝宝保护 → 无法安全复活 → 九转快速消耗
```

## 与当前阵容的核心差异

### 特技去向明细

| 原DF特技 | 去向 | 代价 |
|---------|------|------|
| 放下屠刀 | MW原已有 | 无 |
| 罗汉金钟 | → TG（替换妙法之护） | TG失去妙法之护 |
| 攻心术 | → HS（空余槽位） | 无 |
| 凝滞术 | → MW（空余槽位） | 无 |
| **禁锢术** | **保留（门派技能，非特技）** | 无 |

### 净损失：仅妙法之护

| 失去技能 | 效果 | 影响评估 |
|---------|------|---------|
| 妙法之护（原TG） | 单体+10%法防 | **低** — 情境技能，针对法系单点，长局使用频率极低 |

### 结构性变化（非特技层面）

| 变化项 | 辅助地府 | 满天地府 | 影响 |
|--------|---------|---------|------|
| DF生存 | 5600血/1400防 | 4000血/1150防 | DF易被集火，需保护资源 |
| 清宝宝效率 | 低（MW单烧） | 高（DF+DT满天+MW单烧） | 长局核心优势 |
| 满天花雨 | 单（DT） | 双（DF+DT，满层1806伤×2） | 点杀火力大幅提升 |
| 禁锢术 | ✅ | ✅ | 点杀能力不变 |

**核心取舍：双满天清宝宝效率 + 点杀火力 换 DF生存能力 + 妙法之护**

# 进阶战术原则

> 2026.04 确认

## 清宝宝策略

**核心逻辑：清威胁最大角色的宝宝，不是看宝宝本身威胁**

```
对面女儿一速但我们没一速
  → 清女儿宝宝 → 他下回合出宝宝，没法封出来

对面狮驼/大唐威胁大
  → 清该角色宝宝，减少其出手机会

特定威胁宝宝（力劈、死亡）
  → 可以专门清理，但不是看哪个不爽清哪个

点杀成功后
  → 优先清死人的宝宝 → 死人单位断操作，场上少2个单位，直接拉开差距
```

**不能贪心，该集火就集火**：
- 梦幻宝宝30%神佑（柚子40%），残血≠必死
- 贪心分散火力 → 下不掉宝宝 → 损失远大于集火收益
- 优势是一点一滴积累的，不要因小失大

## 点杀策略

### 大唐点杀判断

| 场景 | 操作 | 原因 |
|------|------|------|
| 大唐能单杀目标（如对面魔王残血） | 横扫千军 | 每杀一人多一层七杀（+1%忽视防御），七杀可叠，积累后越来越强 |
| 依靠团队才能完成点杀 | 破血狂攻 / 平A / 长驱 | 横扫后强制休息一回合，断节奏；对面一回合后就被拉起来 |

### 魔冥点杀时机

```
魔冥叠到3-4层前几回合 → 开始布局点杀

魔冥局中，核心输出是魔王：
  → 魔王打出2500-3000 + 宝宝配合 = 点杀
  → 大唐此时是辅助输出，打个1000血即可，不要贪

魔冥 = 固定增伤，与牛劲无关
  → 没有牛劲也可以点杀，不要因为没有牛劲就放弃机会
```

### 偷花生人头

```
花生（奶妈）倒地 → 对面失去治疗/复活能力 → 极高价值

前几回合有意无意秒到花生血线不满
  → 出其不意集火偷人头

有魔冥机会时，优先找花生点杀窗口
```

## 控制策略

**核心目标：压制对面花生，破坏无限回血节奏**

```
1. 多封对面的花生
   → 封印期间花生无法回血/复活
   → 对面倒地角色拉起后被花生一活又满血，点杀收益归零
   → 压制花生 = 直接提升点杀价值

2. 宝宝盯花生的宝宝
   → 打断花生叠仁心节奏
   → 不能让对面无限活血循环

3. 有魔冥机会 → 找机会杀花生
   → 花生一倒，对面整体治疗链断裂
```

## 优势局辅助操作

**优势局核心：扩大优势，主动进攻，不守摊**

| 操作 | 适用时机 |
|------|---------|
| 花生丢发瘟匣 | 压制对面关键角色3回合无技能/特技 |
| 花生摇铃铛 | 摇走柚子/死亡宠，省清宝宝资源 |
| 花生丢翻天印 | 打开被五彩娃娃保护目标的点杀窗口 |
| 不拉防御圈 | 优势局防御圈价值低，主动进攻扩大优势 |

**花生腰带符石**：改为**门派技能符石**。100级速度圈可覆盖全场5个人，价值远高于其他符石。

## 操作有效性原则

梦幻西游是通过**每回合小优势叠加**，逐步扩大，最终决定胜局的回合制游戏。

**每个角色的操作都重要**，光靠一个主指挥无法精确到10个单位全部操作。

**魔王的特殊责任**（出手最慢，是最适合观察记录的角色）：
- 负责**算对面上端和辅助的愤怒值**（魔王秒到对面上端和辅助，掌握数据最全）
- 负责**标记对面宝宝属性**（出手慢，有观察时间）
- 负责**标记对面出手速度顺序**

**没有指令也要操作**：
- 没收到本回合指令 → 卡血、平A给怒、维持状态等
- 不跳操作
- **一个失误操作带来的影响，可能比装备差异还大**
- 不断操作失误，连无级别都打不赢

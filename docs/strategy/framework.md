# 核心指挥决策框架

## 赛前准备

```
1. 判断对面阵容（212/国标/三攻）
2. 根据对面阵法选择己方阵法（克制优先）
3. 根据阵法安排站位（输出坐伤害位，封系坐速度位）
4. 确认当前白天/夜晚状态（影响地府/物理输出）
5. 检查各角色变身卡是否匹配场景
```

## 战中决策优先级

```
每回合：
1. 有人濒死？→ 单体回血/防御圈/五彩娃娃
2. 关键角色被发瘟匣？→ 清心咒解除
3. 关键角色被大死亡禁锢？→ 乾坤挪移
4. 对面奶妈/关键角色可以点杀？→ 地府挂禁锢 → 集火击杀
5. 正常推进：封系先封，输出集火，奶妈维持
```

## 点杀组合拳

```
标准点杀流程：
① 地府释放禁锢术（50-60%命中，miss则重新等机会）
② 确认禁锢挂上 → 死亡宠继续叠大死亡禁锢（可选，双保险）
③ 集火：大唐横扫（+七杀/拭剑石/魔兽之印加成）或 魔王单烧
④ 目标倒地 → 对面5-10回合无法复活
⑤ 人数优势 → 滚雪球
```

## 竞技馆绝杀逻辑

```
回合1-20：正常推进，积累优势，保留绝杀手段
回合21-23：
  - 判断第24回合己方能否保持人数优势
  - 如果劣势：必须在24回合前完成点杀翻盘
  - 如果优势：保守打法，保住活人数量
回合24+：每回合结算，少死者胜
  - 不要贸然出击导致己方额外减员
  - 对面濒死但不影响计数时可以放过
```

## 夜间特殊处理

```
确认进入夜间：
- 力地府 → 提升优先级，可作为主力输出
- 物理输出无小夜卡 → 物理伤害降低，调整为法系主攻
- 地府自带夜战 → 不受影响
```

## 危机处理

```
奶妈被发瘟匣（3回合废）：
  → 其他角色用特技回血顶替，清心咒尝试解除
  → 此3回合尽量避免大规模消耗

关键角色被大死亡禁锢：
  → 该角色进入"绝对保命模式"，不能倒地
  → 乾坤挪移解除，或熬过10回合
  → 奶妈优先维持该角色血量

全队伤势严重（龟速宠拉起多人）：
  → 奶妈单体技能依次恢复伤势
  → 含疗伤药物优先给关键角色
  → 伤势未恢复的角色不参与进攻
```

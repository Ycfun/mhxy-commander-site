# PK 最高战略原则

> 无限回合适用

**胜负本质：把对面有限资源打光。**
**每回合核心问题：这个操作的资源交换比是否合算？**

## 资源分类

| 类型 | 内容 |
|------|------|
| **有限资源** | 五龙丹、大金香玉、九转回魂丹、蓝量、酒、宝宝 |
| **无限资源** | 特技（愤怒可再生）、法宝（有冷却）、小药、飞镖 |

**有限资源耗尽 = 失去战斗力 = 输**

## 点杀的资源逻辑

```
高代价点杀（不划算）：
  我方：愤怒多次 + 禁锢miss机会成本 + 可能的大金
  对面：仅1个九转（宝宝未清光时顺利复活）
  → 换5回合躺地板，实际收益极小

失败点杀：
  我方：有限资源白白损耗
  对面：近乎零消耗
  → 纯负收益，尽量避免

条件成熟的点杀（划算）：
  前提：对面宝宝大量清除 + 九转告急
  结果：点杀→无法安全复活→多项有限资源同时消耗
  → 真正高收益
```

## 高交换比操作优先级

| 操作 | 我方消耗 | 对面消耗（有限） |
|------|---------|----------------|
| TG封印同一目标 | 蓝量（充裕） | 五龙丹 或 废5-6回合技能 |
| MW单烧宝宝 | 无限资源 | 宝宝储备 |
| HS力劈清耐法/配速 | 无限资源 | 宝宝储备（2下带走） |
| TG笑里藏刀 | 32愤怒 | 70愤怒→逼对面喝酒（有限） |
| 封印不解等自然消退 | 零 | 节省我方五龙丹 |
| 罗汉金钟预判对面爆发 | 120愤怒 | 对面大金消耗↓ |

## 每回合决策框架
```
① 这个操作消耗我方有限资源吗？
   → 是：收益是否显著大于消耗？否则换操作
   → 否：近乎无代价，优先执行

② 这个操作能逼对面消耗有限资源吗？
   → 能：执行
   → 不能：重新评估
```

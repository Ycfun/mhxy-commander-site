# 阵容体系

## 三大阵容体系

| 阵容 | 构成 | 核心战术 | 适用场景 |
|------|------|---------|---------|
| **212** | 封×2 + 辅×1 + 输出×2 | 双封压制，资源消耗 | 剑会（消耗战） |
| **国标** | 封×1 + 地府×1 + 辅×1 + 输出×2 | 点杀，禁锢+击倒 | 竞技馆、群雄 |
| **三攻** | 封×1 + 辅×1 + 输出×3 | 平推，火力碾压 | 速攻场景 |

**没有最强阵容，只有最适合场景的阵容。**

## 阵容选择核心原则

> 2026.04 确认

### 点杀核心组合

**大唐 + 魔王（有魔冥）** = 当前版本最合适的点杀搭配，以此为主导。

大唐是输出核心，定位是打**点杀**，不是清宝宝和打面伤。

### 双封最优解：女儿 + 方寸
- **女儿**：有一速，天宫抢不到一速
- **方寸**：失心 + 必要时催眠；FC能抢3速就尽量抢3速，比4速有用很多
- 速度优先意味着相对脆——要抢速度就接受脆，不存在又快又很硬（除非无级别装备）

### 辅助焊死：花生（化生）

### 其他职业评估

| 职业 | 适用性 |
|------|--------|
| 封天宫 | 可以打，非最优（抢不到一速） |
| 国标/力地府 | 可以玩 |
| 狮驼 | 可以玩 |
| 魔方寸 + 力五庄 | **以清宝宝为主线，非点杀打法**，不是我们的最优解 |

**我们的最优解：大唐+魔王点杀，女儿+方寸双封，花生辅助固定。**

## 阵容变体对比与综合评分

### 辅助地府 vs 满天地府

#### 核心参数差异

| 对比项 | 辅助地府（竞技馆标准） | 满天地府（长局实验） |
|--------|-------------|------------|
| 满天花雨 | 单（DT） | 双（DF+DT） |
| 罗汉金钟 | ✅ 有（唯一真正失去的） | ❌ 无 |
| DF生存 | 5600血/1400防 | 5000血/1200防 |
| 放下屠刀 | DF携带 | MW本来就有，不受影响 |
| 攻心术/凝滞术 | DF携带 | 其他角色可分担 |
| 禁锢术 | ✅ 有（门派技能） | ✅ 有（门派技能，不受套装影响） |

**核心取舍：双满天清宝宝效率 换 罗汉金钟 + DF生存能力**

#### 场景推荐

| 场景 | 推荐 | 原因 |
|------|------|------|
| 竞技馆（24回合） | **辅助地府** | 短局稳，罗汉救命，DF皮厚不拖资源 |
| 群雄（对面无强法系） | **满天地府** | 解决资源耗尽根本问题 |
| 群雄（对面双魔王/强法系） | **辅助地府** | 无罗汉扛不住法系爆发 |
| 剑会/皇宫 | **满天地府** | 长局清宝宝路线，效率碾压 |

#### 满天地府特技重新分配

DF换满天套装后，原有特技需由其他角色承接：

| 原DF特技 | 承接角色 | 代价 | 说明 |
|---------|---------|------|------|
| 放下屠刀 | MW（原已有） | 无 | MW本来就有，不受影响 |
| 罗汉金钟 | **TG** | 替换妙法之护（已确定选罗汉）| TG691速先手，可在对面法系行动前打出 |
| 攻心术 | **HS** | 无（空槽） | HS有一个空余槽位，零代价承接 |
| 凝滞术 | **MW** | 无（空槽） | MW有多余槽位，零代价承接 |

**净损失：仅妙法之护（单体+10%法防，已确认弃用，换罗汉金钟）**

#### 满天地府操作要点
```
前期：DF+DT普攻宝宝叠满天层数（零资源消耗）
      MW单烧宝宝（不打人物，不喂对面愤怒）
中期：满天3层后约1806伤×2，开始威胁人物
      禁锢术择机挂目标，DF+DT+MW点杀
后期：对面宝宝告急→龟速保护失效→九转快速消耗→胜
保护DF：TG天神护体 / 壁垒宠保护，防止DF被提前集火
```

#### 辅助国标不适合长回合（50回合以上）的原因
- 资源消耗大，长局中容易先于对面打光资源
- 清宝宝效率低（单满天），无法快速压缩对面复活空间
- 无双封，打不了五龙丹消耗路线
- 综合来看，长局优势无法发挥，反而容易被拖垮

## 三套阵容核心打法体系

### 212 — 双封消耗体系

**核心逻辑**：用封印把对面五龙丹榨干，五龙丹耗尽后对面技能全废，形成碾压。

**打法路线**：
```
【前期】双封齐上，优先封对面奶妈/关键输出
  → 对面每次解封消耗一颗五龙丹，封的越频耗得越快

【中期】大死亡宠上场，持续攻击目标
  → 10%概率触发大死亡禁锢（10回合无法复活）
  → 等待触发，触发后立即集火击倒

【后期】五龙丹告急 → 对面被封只能普攻
  → 大死亡禁锢触发 + 倒地无法复活 → 胜局锁定
```

**胜负手**：五龙丹耗尽时机 + 大死亡触发窗口（概率因素）

### 辅助国标 — 禁锢点杀体系

**核心逻辑**：禁锢术确保点杀后对面无法快速复活，逼九转消耗，九转耗尽则永久倒地。

**打法路线**：
```
【前期 1-10回合】叠满永久特技状态
  TG：碎甲/圣灵/笑里叠完
  DF+DT：普攻宝宝叠满天层数
  MW：单烧清宝宝（不打人，不喂对面愤怒）

【中期】条件成熟时启动点杀
  条件：对面宝宝 ≤ 2-3只
  流程：DF禁锢术 → 确认命中 → DT横扫+MW单烧+TG五雷集火
  → 击倒 → 立即清该角色剩余宝宝 → 对面被迫用九转

【后期】循环禁锢点杀
  → 每次点杀消耗对面一颗九转
  → 九转耗尽 → 倒地永久无法复活 → 胜
```

**胜负手**：禁锢术命中（50-60%），miss则等下一个窗口；点杀后宝宝清除效率

---

### 满天国标 — 清宝宝消耗体系

**核心逻辑**：双满天极速清光对面所有宝宝，龟速宠无法保护复活窗口，九转在危险时机被迫消耗，加速耗尽。

**打法路线**：
```
【前期】DF+DT双线普攻宝宝，叠满天层数
  目标：尽快达到满天3层（约1806伤×2/回合）
  MW：单烧辅助清宝宝；TG：叠特技状态

【中期】双满天火力全开，清宝宝碾压
  → 对面宝宝加速消耗，双次攻击将神佑触发率压至9%
  → 宝宝告急时换入死亡宠挂大死亡禁锢
  → 禁锢+集火启动点杀

【后期】宝宝清光 → 龟速宠价值归零
  → 对面倒地无安全复活时机
  → 九转在最脆弱时机消耗 → 快速耗尽 → 胜
```

**胜负手**：满天叠层速度 + 保护DF不被提前集火
